WHAT IT DOES
------------
Renames many files at once, right on your website, from your
web browser. You tell it what text to find in the file names, and
it deletes that text or replaces it with something else. It can
also add text to the end of every name.

Example: a folder full of files named like

    A_Hint_of_Something_IMG_2600.jpg
    Blue_Moon_IMG_0042-2.jpg

becomes

    A_Hint_of_Something.jpg
    Blue_Moon.jpg

It only changes the NAME. The file itself (the picture, sound or
video) is never touched, and the extension (.jpg, .mp3...) is
never changed.

It works on any website whose host runs PHP 7.4 or newer, which
is almost every web host today. One file, nothing to install, no
database.


THE TWO VERSIONS
----------------
  rename-files.php        PASSWORD PROTECTED  (recommended)
                          You must set a password before it will
                          run. Anyone visiting the page has to
                          type it to get in.

  rename-files-open.php   OPEN, NO PASSWORD
                          Anyone who finds the page can rename
                          your files. Only use it:
                            - on your own computer (a local test
                              server), or
                            - inside a folder your web host has
                              already password-protected, or
                            - for a few minutes: upload, use, and
                              DELETE it right away.

Both versions do exactly the same thing otherwise. Use one or the
other, not both.


SETTING UP (password version)
-----------------------------
1. Open rename-files.php in a plain text editor (Notepad,
   TextEdit in plain-text mode, Notepad++, BBEdit, VS Code...).
   Not Word.

2. Near the top, find this line:

       const TOOL_PASSWORD = 'change-this-password';

   Change the words between the quotes to your own password,
   for example:

       const TOOL_PASSWORD = 'blue-heron-1996';

   Keep the quote marks and the semicolon. Save the file.
   (The page refuses to work until the password is changed.)

3. Optional settings in the same block:
       TOOL_TITLE    the heading shown on the page
       FOLDER_DEPTH  how many levels of folders to list (3)

4. Upload the file to your website's main folder, the one that
   holds the folders you want to work on. On most hosts this is
   called public_html, htdocs or www. Use your host's File
   Manager or an FTP program (WinSCP, FileZilla, Cyberduck).

5. In your browser go to:

       https://your-site.com/rename-files.php

   and type your password.

For the open version, skip steps 1–3 and go to
https://your-site.com/rename-files-open.php instead.


USING IT
--------
1. FOLDER — pick the folder whose files you want to rename.
   "(this folder)" means the folder the script itself is in.

2. FIND THIS TEXT — type the part of the name to change.

   The * is a wild card. It stands for any mix of letters,
   numbers, hyphens and underscores, and always stops at the
   period before the extension.

       _IMG_*     removes _IMG_2600, _IMG_0042-2, _IMG_A7 ...
       _IMG_2600  removes only exactly _IMG_2600

3. REPLACE WITH — leave it EMPTY to delete the text, or type
   what should go in its place.
   Tip: Find _ and Replace with a space turns underscores into
   spaces.

4. ADD TO END OF NAME (optional) — for example _by_geo_geller.
   It goes just before the extension and is skipped on files
   that already end with it. It can be used on its own (leave
   Find empty) or together with Find.

5. FILE TYPES TO RENAME — tick the kinds of files to include.
   Images, Audio and Video are ticked to start with.
   Each group has "all / none" links.
   "Other extensions" lets you add any type not listed,
   separated by commas, e.g.  psd, ai, srt

   Pages (.htm, .html) start unticked: renaming a web page
   breaks any links that point to it.

6. CHECKBOXES
   Match upper/lower case exactly — on: IMG and img are
   different. Off: they're treated the same.

   Leave a file alone if the text is at the very start of its
   name — on: IMG_2600.jpg and IMG_2600_Front.jpg are not
   changed. Turn it off if you DO want to remove a beginning.

7. Press PREVIEW. Nothing is changed yet. You see every file,
   with the part being removed shown crossed out in red, and the
   new name next to it.

8. If it looks right, press RENAME and confirm.

9. Made a mistake? Press UNDO LAST BATCH (same folder selected).
   Press it again to undo the batch before that, and so on.


WHAT IT WILL NEVER DO (safety)
------------------------------
- Never renames scripts or server files, even if you ask:
  .php .htaccess .htpasswd .ini .js .css .json .xml .py .pl
  .cgi .sh .sql .log .env and similar, or files with no
  extension. Renaming those could break a website.
- Never renames hidden files (names starting with a dot) or
  itself.
- Never works outside the folder it was uploaded to.
- Never renames files inside subfolders of the chosen folder —
  only the files directly in it. Pick a subfolder from the list
  to work on it.
- Never overwrites a file. If a new name already exists, or two
  files would end up with the same name, those files are
  skipped and marked in red so you can fix them by hand.
- Never leaves a file with no name (e.g. IMG_2600.jpg with
  IMG_* removed would become just .jpg — it is skipped).


MESSAGES YOU MIGHT SEE
----------------------
"Open this file in a text editor and change TOOL_PASSWORD"
    You haven't set the password yet. See SETTING UP.

"Wrong password."
    Check spelling and capitals. The page waits 2 seconds after
    a wrong try, to slow down anyone guessing.

"Tick at least one file type."
    Every file type box is unticked.

"name already exists" / "two files would get this name"
    That file was skipped so nothing gets overwritten.

"at front of name — left alone"
    The text is at the start of the name and the "leave alone"
    box is ticked.

"The server won't let this script change files in that folder"
    Folder permissions. In your host's File Manager set the
    folder to 755, or ask your host.

A blank white page
    The file didn't upload completely, or the server runs a PHP
    older than 7.4. Re-upload, or check the PHP version in your
    hosting control panel.


THE UNDO LOG
------------
Each folder you rename in gets a small hidden file called
.rename-log.json. It holds the old and new names so Undo can
work. It's safe to delete once you're happy with the names, but
then Undo can no longer reverse those batches.


WHEN YOU'RE DONE
----------------
Delete the script from your server, or at least rename it to
something hard to guess (e.g. rn-7f3k.php). This matters most
for the open version.
